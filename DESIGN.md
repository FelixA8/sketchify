# Sketchify visual direction

Full-screen sketching tool for people drawing diagrams and rough ideas. The user explicitly requested an Excalidraw remake, so its canvas and floating editing controls are the reference.

The Next.js migration preserves this direction and the existing global stylesheet. React owns the floating controls and dialogs; the imperative Canvas 2D renderer and contenteditable text controller preserve drawing and editing behavior. No font service, component-library restyle, or new visual language is introduced.
